# Sahith Bandi — Data Engineer Portfolio

## Preview locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Included
- Responsive dark-themed portfolio website
- GitHub, LinkedIn, email, phone, and resume download links
- Experience, education, skills, certifications, and project case studies based on the supplied resume

## Publish
Upload `index.html` and `Sahith_Bandi_DataEngineer.docx` to a static hosting provider such as GitHub Pages, Netlify, or Vercel. Keep both files in the same published directory so the Resume link works.

## Notes
- Client names and confidential details are intentionally omitted from the public portfolio.
- Project descriptions and metrics are drawn from the supplied resume. Confirm that all metrics and work examples are approved for public disclosure before publishing.
- The resume is included in DOCX format. A PDF version can be substituted by updating the link in `index.html`.
